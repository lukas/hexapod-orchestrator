Agent registration

Operator credentials can register an agent, record a progress checkpoint, and submit an immutable spending receipt. Use one logical task ID across a parent and its children. Provider receipts must not overlap.

Review execution

The dashboard reports the recorded schedule and recent checks. HTTP and MCP have no run or schedule controls. An enabled scheduler and the Metaagent CLI on the Mac use the same review budget. The shared ledger enforces $20 per run and $80 per rolling day for either provider. Recommendations remain proposals for existing execution owners.
